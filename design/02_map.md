# 02. Карта прототипа ПМРК

Маршруты → экраны → состояния → охват ролей → чек покрытия ФТ.
Реализация маршрутов: `src/app/router.tsx`. Видимость: `src/shared/roles.ts`, `src/app/nav.ts`.

---

## 2. Профиль — 14 вкладок (ФТ-1.1)

`general` · `external` · `affiliation` · `debt` · `statements` · `assessment` · `news` ·
`security`(гейт) · `special-control` · `legal` · `credit-limit`(гейт) · `discussion` ·
`advance-limit` · `protocols`(гейт). Каждая — с `DateActuality`. AI-резюме сверху (при AI on).

## 3. Матрица видимости по ролям (демо проверяемо переключателем)

| Массовая оценка | КК·СБ·АДМ (квота у КК-ДО/СБ) | ПОЛЬЗ/ИСП/РУК → плитка скрыта |

## 4. Демо-сценарии → маршруты

1. Cmd-K → `/counterparties/cp-balt` (AI-резюме). 
2. `/registry` → фильтры → `/counterparties/cp-balt/debt|legal|external` → `…/affiliation`.
3. `/assessments/new` → шаг «Отчётность» (drag-drop) → «Результат» (AI-3).
4. `/limit-requests/new` (AI-черновики) → `/limit-requests/lr-481` (маршрут).
5. `/` → signal-digest → `/counterparties/cp-nevsky`.

## 6. Известные упрощения прототипа (честно)

- Данные — статические фикстуры; реальные API (RTK Query/OpenAPI) не подключены.
- Админ-подразделы «Массовая выгрузка / Справочники / Карантин» — описаны кратко (конструкторы
  маршрутов и формул, монитор интеграций — доведены).
- Авторизация — переключатель роли, не реальный OIDC/JWT; видимость = UX-демо, не контроль доступа.
- AI-ответы срежиссированы (LLM не вызывается) — показывают опыт и границу AI, не качество модели.
- Виртуализация продемонстрирована на ~4,2 тыс. строк (заявленная ёмкость — 200 тыс.).
