# ПМРК — дизайн-прототип рабочего места кредитного контроля

Интерактивный фронтенд-прототип АРМ кредитного контроля ГК «Газпром нефть».
**Consta + React + TypeScript + Vite**, без бэкенда (срежиссированные моки), AI-first.
Цель — продукт, в который хочется заходить: командный центр, командный поиск (Cmd/Ctrl-K),
AI в потоке, первоклассные таблицы — **не очередной портал 2013 года**.

> Дизайн-трек по `ПРОМПТ_дизайн_ПМРК.md`. Источник правды по функционалу — артефакты
> ПМРК (`pmrk_edt.md`, `Классы/22_Фронтенд_структура.md`, `Концепция_AI_в_ПМРК.md`).
> Дизайн меняет **форму подачи**, не объём требований.

---

## Запуск одной командой

```bash
cd web/pmrk-design-prototype
npm install
npm run dev
```

Откроется на `http://localhost:4173`. Целевая среда — Яндекс Браузер на Astra Linux,
десктоп-first (мышь + клавиатура). Светлая тема — основная, тёмная — переключателем.

```bash
npm run build      # сборка прод-бандла (tsc --noEmit + vite build)
npm run typecheck  # проверка типов
```

Требования: Node ≥ 18.

## 5 сквозных демо-сценариев (кликаются end-to-end)

1. **«Быстрая справка» (обычный пользователь).** `Ctrl/Cmd-K` → ввод ИНН/наименования →
   профиль → **AI-резюме риска** сверху. Два действия от запроса до вывода.
   _Переключите роль на «Пользователь» в шапке — интерфейс упрощается (опинионированные дефолты)._
2. **«Глубокий анализ» (контролёр).** Реестр → фильтры-чипы (группа/регион/санкции) →
   проблемный контрагент (**Балтийская ТК**) → вкладки ДЗ/суды/санкции →
   вкладка «Аффилированность» → **интерактивный граф связей** + AI-резюме группы.
3. **«Оценка с объяснением».** Экспресс-оценки → Новая → шаг «Отчётность» →
   **drag-drop PDF** (AI-извлечение, подсветка неуверенных ячеек) → баланс актив=пассив →
   Рассчитать → **AI «почему группа 3»** → выгрузка XLSX.
4. **«Заявка на лимит».** Кредитный лимит → Создать → автозаполнение, авторасчёт уровня
   утверждения → **AI-черновик** полей «справка/обоснование/расчёт» → Отправить →
   визуальный **трекинг маршрута** согласования.
5. **«Утро контролёра».** Командный центр → **signal-digest** «3 контрагента требуют
   внимания сегодня» → переход к сигналу → действие.

## Тумблер AI on/off

В шапке — переключатель **«✦ AI»**. Выключите его, чтобы увидеть продукт **без AI-гипотез**
(демонстрация ценности заказчику): исчезают риск-резюме, объяснения оценки, черновики,
дайджесты, drag-drop извлечение, консультант. Детерминированные числа методик (П-1) остаются.

## Переключатель ролей

В шапке — селектор роли (8 ролей из табл. 13 ЕДТ). Меняется видимость разделов и действий
(«Кредитный лимит» скрыт у ПОЛЬЗ/СБ, «Протоколы КО» — только КК/АДМ, «Мои задачи» скрыты
у ПОЛЬЗ, админ-раздел — только АДМ, квоты массовой оценки и т.д.). SPA только скрывает —
истинный контроль на gateway/сервисах.

## Документы дизайна

- `design/00_foundations.md` — тема Consta под ГПН, токены, плотность, библиотека паттернов,
  система цветовой индикации риска (ФТ-12.8).
- `design/01_decisions.md` — по каждому блоку: что было «портального», как переосмыслено,
  паттерн, встроенная AI-гипотеза, ссылка на ФТ. Защита перед заказчиком и архкомитетом.
- `design/02_map.md` — маршруты → экраны → состояния → роли → чек покрытия ФТ.
- `design/03_requirements.md` — бизнес- и функциональные требования к личному кабинету,
  снятые с реализованного прототипа: все экраны, кнопки, фильтры, визуализации, матрицы
  «роль → элемент», перечень заглушек и границы прототипа.

## Стек и решения

- **Consta** (`@consta/uikit`, `@consta/icons`) — пресет `gpnDefault` = брендбук ГПН «из коробки».
- **React 18 + TS + Vite + React Router 6** (настоящая маршрутизация, 50+ путей).
- Данные — статические фикстуры + `useMockQuery` (имитация задержки → скелетоны).
  AI-ответы — заранее срежиссированные моки, **LLM не вызывается**.
- Кастомные компоненты — только там, где системного нет и это обосновано:
  диаграмма связей (ФТ-4.2), графики (тултип «дата+значение»), виртуализированная таблица.

> Прототип демонстрирует UX и AI-гипотезы. Это не продакшн-код: моки вместо API,
> упрощённая валидация, нет реальной авторизации (роль — переключателем).
